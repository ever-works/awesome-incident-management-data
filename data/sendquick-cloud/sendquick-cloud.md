## Overview

sendQuick Cloud is a notification management platform for the cloud that integrates with public cloud services to monitor systems, applications, services, and networks, flagging issues to staff on duty.

## Features

- Role Based Access
- On Call Scheduling
- Data Analysis
- Incident Tracking
- Custom Alert Templates
- Reporting And Analytics
- Api Integration
- User Management

## Deployment

Cloud-hosted SaaS platform.
