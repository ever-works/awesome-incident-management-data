## Overview

StatusDashboard is a securely hosted status dashboard and incident communication platform for proactive customer communication about issues, accessible anywhere on any device.

## Features

- Reporting And Analytics
- Customizable Dashboards
- Multi Channel Notifications
- Data Analysis
- Mobile App
- On Call Scheduling
- Alert Prioritization
- Customizable Alerts
