## Overview

AWS Personal Health Dashboard is a personalized service that provides alerts and remediation guidance for AWS events impacting your resources. It offers a detailed view of your AWS environment's health, ensuring proactive management and enhanced operational efficiency.

## Features

- Personalized alerts for AWS events impacting your resources
- Event impact and event communication
- Event category, timeline, and metadata
- Event details and event resolution tracking
- Event type classification
- Detailed view of AWS environment health
- Proactive management and operational efficiency

## Pricing

Included at no additional charge with an AWS account (free).

## Deployment

Cloud (AWS-native, SaaS).
