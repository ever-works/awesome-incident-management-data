## Overview

Squid Alerts is a comprehensive incident management tool offering on-call scheduling, escalation chains, and rule-based routing without per-user fees.

## Features

- Webhook Integration
- Multi Channel Alerts
- Api Access
- Integration With Monitoring Tools
- User Management
- Integration With Microsoft Teams
- Sms Alerts
- Alert Prioritization

## Target Segments

- StartUps
- SMBs
- Mid-Market
- Enterprises
