## Overview

OneUptime is a complete open-source observability platform that includes incident management, on-call rotations, log analysis, performance tracking, and more.

## Key Features

- Incident management
- On-call rotations and scheduling
- Log analysis
- Performance tracking
- All-in-one open-source observability platform
- Self-hostable

## Pricing

Free and open-source. Source code and repository available at https://github.com/OneUptime/oneuptime
