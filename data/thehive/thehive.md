## Overview

TheHive is a scalable, open-source security incident response platform that supports collaborative investigation of security incidents.

## Key Features

- Scalable security incident response and case management
- Collaborative investigation of security incidents
- Observable and task tracking
- Self-hostable open-source platform
- AGPLv3 licensed
